
# Microservices Architecture Project (Discontinued)

## Overview

This repository contains a **microservices-based system** that was developed as part of my learning journey into **scalable system architecture and distributed backend design**.

**Important Note:**
This project is **not fully complete**. The final commit represents the **end of the active development phase**, and several components, integrations, and logic blocks are still missing or partially implemented.

---

## Project Status

**Status:** Discontinued
**Final Commit:** Development phase (incomplete)

A significant number of chunks are missing and were planned to be implemented later. However, the project has been intentionally **paused and discontinued**.

---

## Purpose of the Project

Even though the system is incomplete, this project played a major role in helping me:

* Understand **microservices architecture**
* Learn about **service-to-service communication**
* Explore concepts like:

  * API Gateways
  * Authentication services
  * Event-driven design (planned)
  * Scalability and separation of concerns
* Think in terms of **production-level system design**

This repository reflects **learning-by-building**, not a polished production system.

---

## Known Gaps & Limitations

The following areas are **incomplete or missing**:

* Some services are partially implemented
* Message broker integration (e.g., **RabbitMQ**) is not fully functional
* Caching layer (e.g., **Redis**) is not implemented
* Error handling and retries are incomplete
* Documentation and service contracts are partial
* Some configs and environment setups are missing

These gaps exist mainly due to:

* Limited hands-on experience with tools like **RabbitMQ** and **Redis** at the time
* A planned **tech stack shift** before full completion

---

## Why This Project Is Discontinued

* I plan to **rebuild a similar system using a different and more suitable tech stack**
* I want to revisit message queues, caching, and observability **after gaining deeper practical knowledge**
* Continuing this version would add technical debt instead of learning value

This repo is therefore kept **as-is** for reference and learning history.
